# Markint-campaign-analytics
This project analyzes multi-channel marketing campaigns using customer transaction data to identify high-performing marketing channels and provide insights for optimizing marketing spend.  
Business Problem

Marketing teams run multiple campaigns across web, catalog, and store channels.
However, they often struggle to determine:

Which channels drive the most purchases

Which customer segments generate the most revenue

Which campaigns produce the best response rates

How to allocate marketing budgets effectively

This project provides a data-driven framework for marketing optimization.

Tools Used

Python (pandas, scikit-learn)

SQL

Excel

Power BI

Dataset

The dataset contains 2240 customers with information about:

Demographics (Age, Income, Education)

Purchase behavior

Product spending

Marketing campaign responses

Web visits and purchasing channels

Key Metrics

The following metrics were created during analysis:

Total Spend

Total Purchases

Average Order Value

Customer Lifetime Value (CLV)

Campaign Response Rate

Key Insights
Channel Performance

Store purchases generate the largest share of total transactions, while web purchases continue to grow.

Product Revenue

Wine products generate the highest revenue among all categories.

Customer Segmentation

Customers with higher income levels tend to have significantly higher lifetime value.

Campaign Effectiveness

Campaign response rates remain relatively low, indicating opportunities for improved targeting.
